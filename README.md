# CSS Learning & Solo Projects

This repository contains a collection of standalone solo projects that I built while learning **CSS**.

The goal of this repository is to track my personal growth, apply core theoretical concepts in practice (Grid, Flexbox, working with images and colors, etc.), and build a solid foundation for web development.

## 🛠️ Tech Stack & Tools

- **Markup & Styling:** HTML, CSS

- **Language:** JavaScript

- **Development Environment:** VS Code, Git / GitHub, WSL
